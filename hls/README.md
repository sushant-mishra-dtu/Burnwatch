# hls/

This directory currently contains the generated HLS configuration header only:

- `config.h`: generated by `python tools/gen_header.py` from `detector/config.py`.

The documented Vitis HLS implementation is **not present** in this checkout. In particular, there is no `tile_engine.cpp`, C testbench, HLS Tcl flow, exported IP or PYNQ driver here.

The implemented hardware evidence is the separate standalone SystemVerilog core in [`../overlays/rtl_sim/`](../overlays/rtl_sim/) and the hand-written ZedBoard/VIO package in [`../zedboard/burnwatch_zed_vio/`](../zedboard/burnwatch_zed_vio/). Both are required to match the integer reference in `detector/golden.py`; neither is the planned AXI/m_axi HLS overlay.
